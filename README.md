### 🚩 Featured Build

**CLI Log Tampering Detector**
Bash + Python tool that flags tampering in `.bash_history` via SHA-256 hashing and line-count diffing, mapped to **MITRE ATT&CK T1562.003** (Impair Defenses: Indicator Removal). Ships with Telegram bot alerts and an ANSI color-coded terminal dashboard. Built and submitted as an AMCC coursework project.
